# Divisible Number Counter

A Python function that basically counts on how many number that is being given on the list that divisible which is given a divisor default being 2

By having an assert based test and a custom exception it will be raised of the test fails.

This was my very first programming project that was built for a course assignment.

## Example
list_divide ([1, 2, 3, 4, 5]) # returns 2

**Language that was used:** Python

**Run:** 'python main.py'
